Termos de Uso

Ao utilizar o ZapLista, o usuário declara estar ciente de que o aplicativo funciona com dados salvos localmente no próprio navegador/dispositivo.

As listas, produtos, base de produtos, configurações e liberação de acesso podem ser apagadas caso o usuário limpe o cache, os dados do site, o armazenamento do navegador, troque de aparelho, troque de navegador ou reinstale o aplicativo.

É responsabilidade do usuário exportar backup das suas listas sempre que desejar guardar informações importantes.

A liberação do acesso é vinculada ao navegador/dispositivo utilizado. Em caso de perda dos dados locais, poderá ser necessário realizar nova liberação ou entrar em contato com o suporte.

Política de Privacidade

O ZapLista armazena as listas, produtos e preferências do usuário localmente no navegador/dispositivo, usando recursos como armazenamento local.

O aplicativo não exige cadastro pessoal para criar listas e não coleta dados sensíveis como documentos, endereço, senha bancária ou informações financeiras pessoais.

Informações relacionadas à liberação de acesso ou pagamento podem ser usadas apenas para validar o uso do aplicativo e liberar funcionalidades.

Caso o usuário limpe os dados do navegador, cache ou armazenamento do site, as informações salvas localmente poderão ser apagadas definitivamente.

Recomendamos exportar backup regularmente para evitar perda de listas importantes.
